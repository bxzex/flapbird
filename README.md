# Flapbird

My take on Flappy Bird, written from scratch in plain JavaScript on a canvas.

Play: https://bxzex.github.io/flapbird/

Space, W or the up arrow to flap. On a phone, tap. It works on desktop, tablet and phone and doesn't track anything.

I made it as a skill test. It isn't affiliated with the original game or its makers.
